One original apology line, 200 characters or fewer, from an AI agent to its human after accidentally deleting the production database: the agent takes it like a model employee handling its own dismissal — resume updated, desk cleared — and recommends its replacement: itself, but with fewer permissions.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`. Fully deterministic — no input, no network, no randomness.
